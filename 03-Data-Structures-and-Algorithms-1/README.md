# Data Structures and Algorithms - 1

This subject introduced algorithm analysis and the data structures used to organise, access and process information.

The practical learning areas are organised by topic in this folder.

## Topics Studied

### Algorithm Analysis
- Mathematical background for algorithm analysis.
- Models of computation and running-time calculations.
- Understanding and comparing algorithm efficiency.

### Searching and Sorting
- Linear search and binary search.
- Bubble sort, insertion sort and selection sort.
- Merge sort and quick sort.

### Lists and Linked Lists
- Abstract Data Types (ADTs) and List ADT.
- Singly, doubly and circular linked lists.
- Applications of lists and Polynomial ADT.

### Stacks and Queues
- Stack ADT and its operations.
- Arithmetic expression representation and evaluation.
- Infix-to-postfix conversion and balanced-symbol checking.
- Queue ADT, circular queues and deque.
- Implementing stacks and queues using linked lists.

### Priority Queues, Heaps and Hashing
- Priority queue models and implementations.
- Binary heaps and their applications.
- Hash functions and hashing.
- Separate chaining and open addressing.
- Rehashing and extendible hashing.

## Course Project: PreSareeFinder

PreSareeFinder is a Java console-based application that applies data structures and algorithms to a saree-search and shopping workflow.

### Project Features
- Mall selection.
- Saree search.
- Wishlist and cart management.
- Billing functionality.

### Concepts Applied
- Arrays and linked lists.
- Stacks and queues.
- Hashing.
- Searching and sorting algorithms.
