# Frontend Web Development

This subject introduced the technologies and techniques used to build interactive, browser-based applications.

## Topics Studied

### Internet and Web Fundamentals
- Internet fundamentals and HTTP/HTTPS.
- Web client-server architecture.
- Browser basics, web hosting and domain concepts.

### HTML and CSS
- HTML document structure, headings, paragraphs and links.
- Forms, input types and form validation.
- Semantic HTML, tables, media and accessibility attributes.
- CSS selectors, typography, colours, spacing, borders and layouts.
- Flexbox, CSS Grid and responsive design.
- Media queries, transitions and animations.
- CSS functions, custom properties, themes, Bootstrap utilities and SCSS basics.

### JavaScript
- Expressions, operators, conditions and loops.
- Functions, arrow functions and callbacks.
- Objects, inheritance and arrays.
- DOM manipulation and event handling.
- Browser storage and asynchronous programming.
- Promises and exception handling.
- ES6 modules and dynamic form validation.

### APIs and Deployment
- Handling user input dynamically.
- API integration.
- Page-load optimisation and SEO meta tags.
- Understanding CORS.
- Project deployment concepts.

## Course Project: PreSareeFinder

I worked on **PreSareeFinder**, a frontend web application that helps users explore sarees based on budget, shopping mall and type before visiting stores.

The application includes:
- Browsing saree collections.
- Adding items to a wishlist or cart.
- Viewing combined billing.

**Technologies:** HTML, CSS and JavaScript.
