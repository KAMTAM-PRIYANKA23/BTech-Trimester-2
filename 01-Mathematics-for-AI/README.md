# Mathematics for AI

This subject helped me understand the mathematical ideas behind AI computations and how they connect to the way models learn.

## Topics Studied

### Linear Algebra
- Vectors as representations of features such as image pixels, word embeddings and sensor data.
- Vector addition, scalar multiplication, dot products and projections.
- Matrices as transformations, including rotation, scaling and compression.
- Matrix multiplication as a sequence of transformations.
- Tensors and their shapes in AI frameworks.

### Vector Spaces and Dimensionality Reduction
- Matrix rank, linear independence, basis and subspaces.
- Orthonormal bases and the intuition behind Gram-Schmidt.
- L1 and L2 distance, and cosine similarity.
- Singular Value Decomposition (SVD) and Principal Component Analysis (PCA).
- Eigenvalues and eigenvectors and their connection to variance.

### Calculus for Learning
- Functions of multiple variables and partial derivatives.
- Gradient vectors and the direction of fastest increase.
- Jacobian and Hessian matrices.
- Taylor expansion and the intuition behind curvature.
- Loss minimization and its role in model learning.

### Optimization
- Mean Squared Error (MSE) and cross-entropy loss.
- Gradient descent and learning-rate selection.
- Batch, mini-batch and stochastic gradient descent.
- Momentum, Nesterov and Adam optimizers.
- Convergence, local minima and saddle points.

### Mathematical Ideas Behind Modern AI
- PCA through projection matrices.
- Convolution as sliding-window dot products.
- Attention using Query, Key and Value vectors, dot-product attention and softmax.
- Vector-space relationships in NLP.
- Latent spaces in generative models.

## Lab Work: House Price Estimation

As part of the Mathematics for AI lab, I worked on a **House Price Estimation** problem to understand how mathematical operations are used in neural network computations.

The project demonstrates:

- Representing house details as an input vector.
- Using matrix multiplication to process input features.
- Applying weights and biases in neural network calculations.
- Using the ReLU activation function in the hidden layer.
- Calculating the final output through the output layer.
- Implementing the mathematical operations using Python and NumPy.

### Neural Network Architecture

The model uses three input features, two hidden neurons and one output neuron to calculate a house price score.

### What This Exercise Helped Me Understand

This exercise helped me understand how vectors, matrices, weights, biases and activation functions work together in a neural network, and how mathematical calculations can be implemented using Python.
